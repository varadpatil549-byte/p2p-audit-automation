\# 🚀 Enterprise P2P Audit Sampling Automation



> Power Query–based automation for invoice audit sampling in Procure-to-Pay (P2P) operations.



\---



\## 📌 Overview



This project automates audit dataset preparation by integrating enterprise invoice datasets and applying threshold-based audit logic.



The solution eliminates repetitive manual reconciliation, improves standardization, and significantly reduces audit preparation effort.



\---



\## 🎯 Business Objective



The project was developed to:



✅ Automate audit dataset preparation

✅ Reduce manual reconciliation effort

✅ Standardize threshold-based audit selection

✅ Improve audit readiness and efficiency

✅ Reduce dependency on spreadsheet-based validation



\---



\## ⚙️ Key Features



\### 🔄 Automated Data Integration

Automatically merges invoice datasets for audit preparation.



\### 📊 Threshold-Based Audit Logic

Company-code threshold logic applied automatically.



\### 🛡️ Vendor-Based Controls

Specific vendor categories included in mandatory audit scope.



\### ⚡ One-Click Refresh

Instant generation of audit-ready datasets using Power Query.



\### 🎯 Improved Accuracy

Reduced risk of missed invoices and manual errors.
